## 你要的"日本CN2"，先搞清楚是哪一种线路

"日本 CN2 VPS"是个被用滥的标签，背后至少有三种完全不同的东西：

- **CN2 GIA（全程）**：去程回程都走电信 CN2 GIA（AS4809）专属通道，晚高峰稳定，是这类产品里定位最高的线路。搬瓦工东京机房属于这一种。
- **混合优化**：去程走普通 163 骨干、只有回程走 GIA。2021 年半月湾那批日本 CN2 VPS 就是典型——年付 $85 得到 30Mbps 带宽，去程 163、回程 GIA，想要 100Mbps 得加 $360/年。这类机器白天够用，晚高峰体验看运气。
- **软银线路**：接入的是日本软银 bbtec，电信用户晚高峰表现不如 GIA，但价格便宜一截，对部分移动、联通用户反而友好。

买之前先问商家一句"回程是不是三网 GIA"，能过滤掉一大半货不对板的情况。市面上提供真正日本 CN2 GIA 的商家本来就不多，多数产品是软银或普通 CN2，主因就是成本——CN2 GIA 的 IP transit 市场价约 120 美元/Mbps，日本机房又比美西更贵。
